# 009 图表工作台与探索预览

状态：用户三轮访谈确认全部建议，已于 v0.8 实现。

图表是工作中心。顶部标的搜索、添加指标、模板、检查按钮；右侧观察列表负责分组排序归档；底部可收起的信号、决策和历史面板。日常操作不离开图表，原管理页保留为高级入口。

指标修改立即在选定报告/行情快照上预览，无网络采集，无正式事件写入、无通知。保存模板仅更新展示配置；加入监测/保存监测才更新后台规则。共享规则默认复制给当前标的，明确选择共享更新时列出受影响标的。新监测下次检查生效，预览不冒充正式报告。

浏览器保留当前标的、模板、图层可见性、可视范围、布局、探索草稿。草稿按报告和标的隔离；模板跨标的应用。决策草稿也按报告和标的恢复。历史报告默认还原当时配置，临时探索结果单独标识；用于决策时服务端重算并保存独立依据，原报告不变。

搜索现有已验证目录，显示市场、来源；搜索不到展开手动添加，启用前联网验证。新标的不自动绑定监测。配置保存、快照预览、正式检查三种状态分别显示时间和版本。

保留Python/FastAPI/SQLite/Lightweight Charts，无新增运行依赖。workspace模块负责局部命令、预览、模板与行情快照引用；继续复用configuration校验、strategies纯计算与runner正式检查。模板追加版本，工作草稿本机存储。限制最多24个探索指标，不引入任意表达式或自动交易。
