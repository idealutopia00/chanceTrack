# ADR 006：以交易时段统一处理所有市场，替代单标的盘中开关

日期：2026-11-17。状态：已实施。取代ADR 005中仅对科创创业50放开当天的局部策略。

问题：科创创业50修复后，黄金依然因默认“昨天截止”被排除。给黄金再添加股票相同的include_intraday开关，会把9:00开盘、15:30收盘和夜盘错误地当作A股9:30/15:00；以自然日截止还会丢失普通周五夜盘中归属于周一的真实日K。

选择：新增market_sessions模块，观察对象统一配置cn_equity/sge_gold/us_equity。Yahoo与东方财富适配器都只解析真实OHLC，交由同一Interface判断交易是否已开始、日K是否完成，再校验已纳入的数据。取消include_intraday及前一天请求截止，东方财富请求最新日K，带时间参数减少缓存影响。

状态按交易日整根日K判定：休市间隔不等于日K收盘；午休、凌晨结束后的日盘前、普通周末仍可能属于未完成黄金交易日。黄金普通周一从上周五夜盘开始；只有正常连续交易日或普通周末允许前一交易日晚夜盘，长假前无夜盘，不跨假期猜测连续交易。日间9:00–15:30从2019年起连续，无股票式午休。

中国日历使用现有chinese-calendar并排除调休周末。它不是交易所临时公告同步；特殊临时停市或超出日历年份需要更新规则。美股用纽约时区，最新交易日优先用Yahoo currentTradingPeriod.regular处理真实开收盘及半日市，缺失时按常规时段；历史源本身缺少的休市日不生成日K。

所有市场统一等待收盘后5分钟再确认。来源未交付最新日K时只保留真实数据，不能因为到了开盘时间就造一根。未开始的源占位行不纳入指标；最新未收盘行记provisional_date，临时交叉不写events。分析规则macd-market-sessions-v4保存session_policy、profile、时区、交易日、开收盘、确认时刻及判定来源。负的自然日年龄在夜盘中不表示未来价格，页面以行情交易日呈现。

范围：统一取数和状态，不改变14:35日任务或加入行情自动循环/实时推送。刷新一次保存一次快照，历史不会随现在的市场时钟被改写。
