# Chance Track 当前设计（v0.4）

日期：2026-11-17。用户已更正：针对指数做决策，展示真实 K 线，结合成熟开源项目改善外观。当前文档取代 [v0.1 基金方案](archive/design-v1.md)，旧报告不改写。

## 产品行为

工作日 14:35 自动检查市场日线，本地通知；用户在观察台切换标的，查看 K 线、MACD 和金叉/死叉事件，然后记录自己的决定及执行情况。只提供观察，不下单。历史报告保留当次行情和计算结果。

## 观察对象

| 对象 | 身份 | 数据源 | 单位 |
| --- | --- | --- | --- |
| 标普500 | ^GSPC | Yahoo Finance chart | 指数点 |
| 纳斯达克100 | ^NDX | Yahoo Finance chart | 指数点 |
| 费城半导体 | ^SOX | Yahoo Finance chart | 指数点 |
| 科创创业50（双创） | 2.931643 | 东方财富日 K | 指数点 |
| 黄金 Au99.99 | 118.AU9999 | 东方财富日 K | 元/克 |

黄金是上金所现货品种，不是股票指数。默认选择与国内黄金基金底层资产较接近的 Au99.99，界面始终显示品种与单位。双创继续明确解释为科创创业50。全部对象使用真实开、高、低、收行情，没有基金代理或合成 OHLC。

Yahoo 每次请求约两年日线，东方财富最近 600 根日线。源响应需核对 symbol/code、市场或 INDEX 类型；验证日期唯一升序、价格有限为正、高低价包含开收、成交量非负、序列长度一致。异常停止该标的分析，不静默替换成基金。

## 盘中与收盘口径

科创创业50启用 include_intraday：请求截止日期包含检查当天，并附请求时间参数减少缓存影响。北京时间09:30之后，如果数据源返回当日真实日K，则保留开高低收和当前价；09:30之前不纳入当天行。午间休市仍标为未收盘。15:05之前当日行记作 provisional_date，15:05及以后重新取数时才按收盘日线处理。五分钟缓冲不代表行情源承诺及时结算；公共行情仍可能延迟。

科创创业50盘中时：K线末根及最新DIF/DEA/柱体包含今天当前价格，显示“盘中未收盘”和“临时值”；最近已收盘日的信号单独展示。盘中金叉/死叉只记 preview_event，不写入确认事件表，随价格反转可以消失。收盘后重新取数，若交叉仍存在才按 event_date=当天记录正式事件。仅有当天预览数据时，仍要求至少120根已完成日线用于预热。

其他标的口径暂不变：中国黄金现货使用前一日期及以前日线，避免在未定义其夜盘规则前误判；美国指数等待当地交易日16:30（America/New_York，自动处理夏令时）后才纳入。不能将各品种当作同一交易时段。

“立即更新”重新向源取数，源未更新或尚未提供今天日线时不会伪造K线。页面每30秒轮询只是检查报告，并非行情自动刷新；定时取数仍是14:35日任务及失败重试，需要更新盘中价格时主动点击。历史报告保留当时看到的盘中状态，不随时间经过自动变为已收盘。

## Module 与 Interface

| Module | Interface | 职责 |
| --- | --- | --- |
| data | fetch(asset, as_of) → snapshot | 两个具体来源的请求、身份/OHLC 校验、完成日线过滤、来源与采集时间 |
| analysis | analyze(snapshot, as_of) → result | 用收盘计算 MACD、交叉事件及图表序列；无网络或数据库操作 |
| storage | 保存/查询报告，追加决策 | SQLite 事务、事件去重、快照及不可覆盖历史 |
| runner | run(...) → report_id | 工作日调度、补检、错误隔离、保存与通知 |
| notifications | notify(title, message) | macOS 原生通知 |
| web + static | 本地页面、表单与图表交互 | Jinja2 模板、Lightweight Charts、切换及回看 |

单应用按职责分 Module，普通函数组成 Interface，不增加单实现抽象类、插件系统或事件总线。采集及通知在 runner 调用处可替换。图表端只渲染，不自行重新计算 MACD，避免图表与信号口径分叉。

## MACD 计算

规则 macd-market-intraday-v3，basis=market_ohlc，至少 120 个样本。价格使用 close；EMA12/EMA26、DIF 的 EMA9 均为 pandas ewm(adjust=False)，以首个样本初始化。DIF=EMA12−EMA26，DEA=EMA9(DIF)，柱体=2×(DIF−DEA)。

前一根 DIF−DEA≤0 且本根>0 为金叉；前一根≥0 且本根<0 为死叉。历史标记在达到 120 样本后生成；正式事件使用最近一根已完成日线的交叉，event_date 与盘中展示的 bar_date 可能不同；盘中交叉单独为 preview_event，不把整段历史交叉补发为新事件。超过七个自然日未更新则抑制新事件。

K 线使用原始 OHLC；MACD 序列、交叉标记、最新数值均来自同一次 analysis 结果。图表默认展示最近约 126 根，可切换 63、252 根或全部，缩放不重新初始化指标。样本窗口随采集时间变化，报告保留完整输入，可复现当次结果，但不声称两年窗口等价于无限历史 EMA。

## 图表与页面

采用开源 TradingView Lightweight Charts 5.0.9（Apache-2.0），锁定版本、本地托管 JS，附 LICENSE 和 NOTICE，页面保留 TradingView 署名与链接。与 TradingView 图表软件、行情服务没有绑定关系。

- 顶部五个行情卡片切换观察对象，显示最新日线涨跌幅与日期，科创创业50未收盘时注明盘中。
- 单图两 Pane：真实蜡烛图与 MACD，共用时间轴、十字线、拖动和缩放。
- 红涨绿跌；DIF 金色、DEA 紫色；金叉/死叉可切换显示，未收盘标记冠以“临时”。刷新报告后记住选中的标的。
- 右侧信号状态、来源和决策表单；下方日志、快照、历史报告。
- CSS 自适应桌面及手机；无远程字体、CDN 或前端构建工具依赖。

## 页面更新

“立即更新”通过受 CSRF 保护的 POST /refresh 重新采集所有启用标的，保存一份手动报告，不发送弹窗，不受工作日、自动重试次数和截止时间约束；科创创业50包含当日盘中日线，其他品种仍按各自收盘口径。更新期间显示状态并禁止重复点击。无未保存判断时跳转新报告；有草稿时只提供新报告链接，保留当前页面。

页面每 30 秒请求 /api/update-status（只查报告元数据和文件锁，不取行情）。后台生成新报告后显示提示，不主动替换当前报告。每只标的分别显示行情交易日期、最近检查时间与成功采集时间，沿用快照显示来源报告。记录草稿的表单用 Set 跟踪，离开页面前提示未保存内容；页面刷新不会自动保存草稿。

## 历史与兼容

每次报告保存观察对象副本、来源 URL、采集时间、全部 OHLC、规则参数、图表序列及分析结果、代码版本和包含静态资源/锁文件的 SHA256。新取数不覆盖旧报告，决策只追加。

旧 macd-unit-nav-v1 报告继续显示原净值及当时指标，界面明确标注历史基金口径，不绘制虚构 K 线。事件 key 使用标的、event_date（兼容旧报告 bar_date/nav_date）、规则版本和类型；不能把昨日已确认交叉记到今天的临时K线上。定时检查按日期、规则版本及尝试序号去重，升级后的指数检查不会被当天旧基金报告挡住。每次重试单独保存，parent_report_id 关联前一次报告；成功项沿用原快照，保留 checked_at、fetched_at 和 origin_report_id。旧报告和其决策不变。

## 调度、运行与异常

沿用中国工作日、14:35、当日补检和 15:00 后补发标记。每五分钟唤醒一次检查：当天定时报告全部成功后不再取数；如有 status=error，仅重取失败标的，两次尝试开始时间至少相隔五分钟，含首次最多三次，15:00 后不启动重试。15:00 后首次恢复运行仍可补检一次。warning（例如陈旧行情）不自动重试，disabled 项不重试。每次尝试保存新报告，不覆盖失败报告；通知失败仍会重试。不是交易所休市日历，不补扫全部停机历史信号。

runner 的文件锁由 CLI、定时任务、HTTP 手动更新共同使用；运行中的任务互斥，新请求明确返回忙碌，不排队、不重复采集。数据在 ~/Library/Application Support/ChanceTrack/data，运行副本在 runtime，日志在 ~/Library/Logs/ChanceTrack。源码或观察清单变更后重新安装更新；不依赖源码外接卷在线。

本地页面只监听 127.0.0.1，Host 限制、CSRF token、模板转义沿用。数据库备份用 SQLite backup。通知提交成功不等于用户已读。

## 验收与限制

首版重点验证行情日期清楚、报告可追溯、交叉去重、决策历史和图表可读。无回测、盈利验证、止盈止损、仓位建议、基金交易或自动下单。公开非官方接口可能变动，失败会明确提示。科创创业50以外品种的盘中行情、行情自动刷新及收盘后自动确认取数尚未实现。
