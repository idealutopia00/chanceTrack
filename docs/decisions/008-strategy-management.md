# 008 标的与多策略管理

状态：用户确认，已于 v0.7.0 实施并部署。

标的生命周期为启用、停用、归档，不删除已有历史。标的与命名策略配置通过绑定关联；策略分组仅组织展示，不隐含逻辑。配置采用 SQLite 追加版本，报告保存完整配置快照，重试沿用首次版本。

首批策略：MACD(12/26/9)、双均线(20/60)、布林突破与回归(20周期、2倍总体标准差)。这些是功能默认值，不是经过验证的投资参数。布林比较相邻两根收盘价与各自轨道；不将触轨等同于交易建议。

组合为一个触发策略加可选过滤器，同一根日K判断，禁止组合嵌套。过滤器支持高于/低于布林中轨。缺数据为无法判断，过滤失败为条件未满足。盘中暂态与收盘确认分离。

新增策略不自动绑定。新绑定的历史已确认事件仅供参考，不补发；后续新收盘事件依标的、策略配置版本、日期、事件去重。图表来自报告快照，显示可开关的均线、布林带、MACD；策略结果可定位日K。

实施顺序：配置与校验 → 纯策略计算 → runner/通知集成 → 管理与图表页面 → 回归测试与部署。旧报告、决策、通知原文不改写。保持 Python/FastAPI/Jinja/SQLite/原生JS，无新增运行依赖。
