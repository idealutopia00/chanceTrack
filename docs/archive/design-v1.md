# Chance Track 首版设计

状态：首版实现方案，2026-11-17。需求来自本次访谈，实施与核查结果见 README。

## 已确认需求

- 用户持有指数被动基金，缺少明确观察信号和持续检查习惯。
- 系统采集和分析，由用户判断；不连接交易账户、不执行交易。
- 观察标普500、纳斯达克100、黄金、双创、费城半导体。
- 美股方向按代表 QDII 基金已公布净值计算；不是实时指数或净值估算。
- 中国工作日 14:30—14:45 本地弹窗；默认 14:35，错过后补检。
- 记录买入/卖出/持有/观望及未执行/已提交，可选备注。
- 首月验收重心：检查稳定、日期清楚、事件不漏记、决策可回看。

## Module 与 Interface

| Module | Interface | 内部职责 |
| --- | --- | --- |
| 数据采集 data | fetch(asset, as_of) → snapshot | 请求、身份校验、JSON 提取、日期/净值校验；不执行远端 JS |
| 指标分析 analysis | analyze(snapshot, as_of) → result | 固定口径计算、交叉判断、数据质量抑制 |
| 历史存储 storage | 保存/查询报告，追加决策 | SQLite 事务、事件唯一键、快照及历史 |
| 每日检查 runner | run(...) → report_id | 日历、串联、错误隔离、去重、通知重试 |
| 通知 notifications | notify(title, message) | macOS osascript，异常交给调用方记录 |
| 本地交互 web | 本地 HTTP 页面与表单 | 报告阅读、决策追加、快照导出 |

一个 Python 应用，各 Module 使用普通函数；没有单实现的抽象基类、事件总线或通用插件系统。采集与通知在 runner 调用处可替换，指标计算不涉及网络和数据库。SQLite 是持久化中心。默认数据放在用户 Application Support 目录，源码运行与部署运行共用。

## 计算口径

规则版本 macd-unit-nav-v1。按基金完整单位净值历史、日期升序计算：

- EMA12 和 EMA26：pandas ewm(span=n, adjust=False)，首个净值初始化。
- DIF = EMA12 − EMA26；DEA = DIF 的 EMA9；柱体 = 2 × (DIF − DEA)。
- 前一个样本 DIF−DEA ≤ 0、最新 > 0 为金叉；前一个 ≥ 0、最新 < 0 为死叉。
- 至少 120 个样本；最新净值距离检查日超过 7 个自然日则标记陈旧，不生成交叉事件。
- 仅检查最新两个净值样本，不把历史交叉当作当天事件，也不承诺扫描停机期间全部历史交叉。
- 非复权单位净值会受分红、折算影响。源的 unitMoney 在最近 120 样本非空时，保留指标但抑制事件。该检查依赖源标注完整性，首版不声称已获得总回报复权数据。
- 初次检查如最新样本存在交叉，记录为首次检测；重复运行仍显示交叉状态，但不再计为新事件。
- 状态和事件属于观察，不代表已验证的盈利策略。

## 调度及异常

Asia/Shanghai。排除周末，使用 chinese-calendar 判断中国法定工作日；行政调休周末不运行。不是交易所日历，海外休市通过净值日期呈现。日历包不覆盖年份时明确报错，需更新依赖，不猜测。

launchd 在 14:35 和每 300 秒调用检查；14:35 前无操作，当天成功生成定时报告后不重复采集。恢复运行后在当日时间 >=14:35 时补检；15:00 后明确标注补发。不补造以前日期的日报。CLI 文件锁防止本机并发检查。

单标的错误保存在报告中，不影响其他标的。不用旧缓存冒充新采集。当天定时报告如包含采集失败，仍算已完成，修复后可手动再检查；首版不自动重新采集该报告。通知失败保存错误，下次调度重试；提交给系统不代表用户已读。崩溃发生在系统收到通知与数据库确认之间，可能重复通知一次。

## 可追溯性

reports 保存不可变 JSON：观察清单副本、数据源地址、完整解析净值和公司行动、采集时间、计算参数及版本、结果、Git revision、源文件与依赖锁 SHA256。源后来修订数据时新建报告，旧快照不变。哈希标识代码，不代替源码备份；应保留 Git 提交和 uv.lock。安装器复制运行快照到用户目录，源码修改后需显式重新安装，不热更新运行副本。

events 通过标的 + 净值日期 + 规则版本 + 事件类型唯一去重。decisions 只追加，关联 report_id 和 asset_id，每次修改成为新记录。没有追求完整 event sourcing，SQLite 表足以满足当前历史查询。

## 本地交互与安全

仅监听 127.0.0.1，限定 Host，表单使用进程级 CSRF token，模板默认转义。无外部字体或脚本。数据库包含个人决策，保留本地，备份时使用 SQLite backup 而不是运行中只复制主文件。

## 首版范围与后续

不含回测、持仓同步、收益归因、止盈止损、自动下单。原生通知展示报告地址，首版不保证点击通知能打开页面；手动打开本地页面即可查看。未来新增通知渠道只改发送处，不改分析。

需要后续确认/验证：费城半导体参考数据、分红复权方案、真实休眠唤醒行为、通知权限与端到端定时运行。第三方公开源无稳定性承诺，身份和格式异常时停止该标的分析。
