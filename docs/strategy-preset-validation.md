# 日线观察预设 · 样本外验证

本次固定工作台默认参数，以 2026-04-01 为开发与样本外分界，未按结果改动参数。数据截到 2026-11-19 的已完成日线。四个样本各留 199 根历史用于共同预热，窗口跨越分界日或样本末尾时排除。退出配对中的未完成观察只计入启动数。仅使用同一市场和同一标的的 OHLC 对照。

- 国内指数使用中证指数官方 931643 人民币价格指数的日 OHLC。 [中证日线](https://www.csindex.com.cn/csindex-home/perf/index-perf?indexCode=931643&startDate=20241119&endDate=20261119)
- 美股使用 Yahoo 的标普 500、纳斯达克 100、费城半导体日 OHLC。三份数据的元数据均为美元纽约时区，实际覆盖日期一致，可用于相对基准比较。 [标普 500](https://finance.yahoo.com/quote/%5EGSPC/history/) · [纳斯达克 100](https://finance.yahoo.com/quote/%5ENDX/history/) · [费城半导体](https://finance.yahoo.com/quote/%5ESOX/history/)
- 黄金 Au99.99 的东方财富接口断连，上海黄金交易所日表在当前执行环境返回 HTTP 403。已验证的官方样本短于共同预热期，缺连续已收盘 OHLC，暂无法报告有效样本或样本外统计。 [上海黄金交易所日表](https://www.sge.com.cn/sjzx/quotation_daily_new?start_date=2024-01-02&end_date=2024-01-05&inst_ids=Au99.99)

用信号后一根可交易日线的开盘价作为进场代理；五日窗口用第五日收盘，唐奇安退出用退出确认后下一根开盘，单边成本假设 0.10%。指数点用于价格代理，未指定可交易产品或实际滑点。回调修复比例按信号后 5 个交易日内是否收回 SMA5 计算，便于和单用 RSI 对照。最大不利波动以窗口最低价衡量，唐奇安回撤使用收盘路径，跟踪退出峰值回吐使用观察内最高价。相对超额用信号后第一个共同交易日开盘和第 20 个共同交易日收盘，各腿应用同一成本。

脚本接受显式路径的市场 OHLC 快照，字段同项目采集数据，不读取线上数据库。给定这些输入即可重新计算。

```sh
uv run python scripts/compare_presets.py --benchmark '^GSPC' csi.json sp500.json nasdaq100.json sox.json
```

少量事件或零样本时，暂无法据此判断预设值得保留。
