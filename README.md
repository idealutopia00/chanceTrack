# Chance Track

本地市场观察台：跟踪指数与黄金，查看真实K线和MACD，自主决策并保留历史依据。

## 运行

```sh
uv sync --python 3.12
uv run chance-track check --no-notify
uv run chance-track serve
```

打开 http://127.0.0.1:8765 。若已安装自启动，无需重复运行serve。

“立即更新”获取最新行情并创建报告；有未保存的判断时保留当前页面。“查看通知”只读查看摘要，不重复发送系统通知。后台每30秒检测新报告，不是实时行情推送。

## 如何理解信号

- **本次观察快照**：每个标的一行，展示本报告检查时的状态，不冒充实时行情。
- **上一收盘日参考**：盘中标的上一根已收盘K线上的交叉，单独放置，不能当作今天新产生的信号。
- **未收盘**：临时MACD可能改变，临时交叉不记成确认事件。
- **已收盘交叉**：只说明该交易日满足MACD金叉/死叉条件，不代表收益已经验证，也不是自动买卖指令。
- **已通知**：系统通知已提交，和市场是否收盘是两种独立状态。

例如黄金最新行情是11月17日未收盘，而11月16日已形成死叉：本次观察快照显示17日临时状态；16日死叉放在“上一收盘日参考”。旧报告保存的是当时快照，不会随当前时间自动更新。

## 数据与交易时段

| 标的 | 数据源 | 时段口径 |
| --- | --- | --- |
| 标普500、纳斯达克100、费城半导体 | Yahoo Finance真实指数OHLC | 纽约时区，优先采用源提供的开收盘时间，支持夏令时与半日市 |
| 科创创业50 | 东方财富真实指数OHLC | 09:30–11:30、13:00–15:00 |
| 黄金Au99.99 | 东方财富上金所现货OHLC，元/克 | 日间09:00–15:30，夜间20:00–次日02:30；普通周五夜盘属于周一交易日 |

所有市场统一在收盘后5分钟、再次取数时确认。中国节假日与普通黄金夜盘按现有日历处理，临时特别休市需要更新规则。源可能延迟，采集时间不等于成交时间。

MACD采用12/26/9、EMA `adjust=False`、柱体`2*(DIF-DEA)`，至少120根已完成日K。新分析不使用基金净值代理；旧基金报告保持原口径。

## 检查与部署

```sh
uv run python scripts/check_project.py
uv run pytest -q
node tests/check_updates.mjs
uv run python scripts/install_launchd.py
```

安装器先验证Python、模板、静态文件、观察清单及依赖锁，检查失败时不会停止现有程序。源码及清单更改后重新安装；运行副本放在用户目录，不依赖源码外接卷在线。

工作日14:35检查。失败项至少间隔5分钟重试，含首次最多3次，15:00截止；晚间首次恢复仍可补检。成功项保留原快照。手动更新不占用自动重试次数。系统通知区分首次记录与首次通知，静默检查不消耗通知名额。

```sh
uv run python scripts/install_launchd.py --remove
```

卸载自启动只移除任务，保留数据。

## 项目目录与历史

- `chance_track/`：采集、市场时段、指标、存储、展示、通知和本地网页。
- `chance_track/templates/partials/`：图表、标的详情、通知等独立模板。
- `tests/`：行为、历史兼容、静态资源及部署检查。
- `scripts/`：部署前检查与macOS安装/卸载。
- `docs/`：当前设计、开发说明、决策和实施记录。
- `docs/archive/`：旧方案和静态预览，仅供追溯，不是实时行情。

实际数据库：`~/Library/Application Support/ChanceTrack/data/chance-track.sqlite3`。
运行副本：`~/Library/Application Support/ChanceTrack/runtime`。
日志：`~/Library/Logs/ChanceTrack/`。源码目录旧`data/`为早期开发数据，保留但不作为默认数据库。

每次检查保留完整行情、规则和代码指纹，决策只追加。备份使用SQLite backup，不能在运行时只复制数据库主文件：

```sh
uv run python -c 'import sqlite3; from pathlib import Path; folder=Path.home()/"Library/Application Support/ChanceTrack/data"; source=sqlite3.connect(folder/"chance-track.sqlite3"); target=sqlite3.connect(folder/"backup.sqlite3"); source.backup(target); target.close(); source.close()'
```

详见[当前设计](docs/design.md)、[开发说明](docs/development.md)、[实施记录](docs/implementation-log.md)。依赖固定于`uv.lock`；源码尚未提交时，以代码指纹标识，长期精确重现还需保留对应源码。

## 标的与策略管理

打开观察台侧栏的“标的与策略管理”（`/manage`），可新增、编辑、停用、归档标的，并绑定命名策略配置。预置MACD、双均线、布林突破和布林回归；新增配置不会自动绑定。组合策略支持一个触发配置加可选布林中轨过滤，分组只影响展示。

保存配置会追加版本，下一次检查使用新版本。已有报告、通知原文和决策保持原样；管理页可回看配置修改历史。布林默认20周期/2倍总体标准差，仅为功能默认值。图层可开关，点击策略结果可定位日K。

## 图表工作台（v0.8）

日常操作均在观察台完成：顶部搜索/添加标的、添加指标和套用模板；右侧观察列表切换、分组、排序和归档；指标名称旁的设置按钮直接调整参数。

修改指标会在已有行情上生成“探索预览”，不采集行情、不改变自动提醒。保存模板只保存展示组合；“加入/更新监测”才修改后台规则，下一次正式检查生效。共享规则默认复制给当前标的；共享更新会列出影响范围。

探索草稿、图层开关、缩放、布局和决策文字在当前浏览器自动恢复。浏览器清理本地存储会清除这些草稿；已保存模板、报告、配置与决策仍在SQLite。记录判断时可以选择原始报告或独立探索依据，便于以后追溯。
