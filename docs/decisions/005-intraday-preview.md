# ADR 005：科创创业50纳入当日盘中行情，临时与确认信号分开

日期：2026-11-17。状态：已实施。更正 ADR 003/004 中“所有品种只使用完整日线”的部分。

用户指出：科创创业50正在交易，但立即更新后仍是昨天。回归复现定位到两处主动排除：东方财富请求 end=昨天，以及解析器丢弃 date>=今天。行情源实际返回2026-11-17的真实OHLC，原实现不符合15:00前判断的产品目标。

选择：仅科创创业50启用 include_intraday，取数截止日期改为今天并附请求时间以减少缓存影响。09:30之后纳入源提供的当天日K，15:05之前标记 provisional_date；午休仍未收盘。黄金交易时段含夜盘，不直接套用A股规则，保持原口径；美股仍为收盘数据。

分析升级 macd-market-intraday-v3。盘中最后一根用当前价格计算临时MACD，图表、状态和preview_event一致。正式event独立取最近已完成日线，保存event_date；存储去重以event_date为准，不把昨日交叉错记成今日确认。临时交叉不插入events表。15:05后主动重新取数，如果仍满足交叉，才能生成当日已确认事件。

界面：行情卡片显示盘中标记，图表标注“盘中未收盘”，MACD显示临时值，交叉标记冠以“临时”；右侧区分盘中观察与最近已收盘日的信号。公开行情可能延迟，采集时间不是最新成交时间，不能承诺逐笔实时。

不增加自动行情轮询或收盘取数任务。现有30秒轮询仅检测新报告；14:35日任务和失败重试保持原节奏，需要刷新盘中价格时点击更新。页面保留选中的标的，避免更新后回到标普500。

验证：固定时钟复现“源有今天K线却显示昨天”的失败测试；修复后验证请求包含今天、开盘前排除、午休未收盘、15:05确认、临时交叉消失不写确认事件、收盘后确认可正常入库、昨日已确认事件日期不被今日预览污染。旧报告按当时快照保留，不因当前时间变化改写。
